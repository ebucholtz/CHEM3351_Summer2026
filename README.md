Repository for CHEM3351 Cheminformatics at University of Health Sciences and Pharmacy in St. Louis for Summer 
Session 1 in 2026.

Modules will be covered during the course of the summer. These activities are written as guided inquiry and you should be able to complete them without much outside assistance. Most of the homework problems can be solved just using information learned in the activity.

# Environment

The CHEM3351.yml file is the environment I set up for my WSL Ubuntu miniconda environment. All dependencies were added via conda-forge.
I used the --from-history flag to improve cross platform compatibility.
